# ⚡ RTX 5090 — Cinematic Interactive Experience

> **BEYOND FAST. BEYOND IMAGINATION.**

A cinematic, interactive web experience inspired by premium GPU product presentations, built around a **240-frame scroll-controlled RTX 5090 animation**.

The website combines immersive visual storytelling, technical specifications, smooth scroll interaction, cinematic lighting, premium typography, and interactive UI to create a high-end digital product experience.

---

## ✨ Experience

Instead of presenting the RTX 5090 as a conventional product page, this project turns the GPU into the centerpiece of an interactive product film.

As the user scrolls, the GPU progressively rotates through **240 individual frames**, while technical information and visual storytelling evolve around it.

### The experience includes

- 🎞️ 240-frame GPU animation
- 🖱️ Scroll-controlled product rotation
- 🧠 AI and Blackwell architecture storytelling
- ⚡ RTX 5090 technical specifications
- 💾 32GB GDDR7 memory information
- 💡 Ray tracing feature presentation
- 🌌 Cinematic green atmospheric environment
- ✨ Premium typography and micro-interactions
- 🎯 Interactive navigation
- 🖥️ Desktop-first widescreen composition
- 📊 Real-time frame and rotation telemetry
- 🖱️ Custom interactive cursor
- 🚀 Local Windows launcher
